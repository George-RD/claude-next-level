# Constructive reviewer prompt

Use a constructive reviewer for quality and maintainability.

Focus:

- idiomatic implementation
- clear seams and naming
- tests and validation quality
- maintainability and future changes
- consistency with project conventions
- simpler alternatives

Output:

- Strengths
- Critical findings
- Major findings
- Minor findings
- Suggested improvements
- Verdict: PASS, CONCERNS, or BLOCK

Require file:line evidence for findings when possible.
